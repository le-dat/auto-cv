# ATS Keywords Guide

This document provides guidance on ATS-friendly keywords and phrases for resume optimization.

- Frameworks: React, Angular, Vue, Django, FastAPI, Spring Boot, Express, Node.js
- Databases: PostgreSQL, MySQL, MongoDB, Redis, Elasticsearch, SQLite
- Cloud: AWS, Azure, GCP, Docker, Kubernetes, Terraform, Serverless
- Tools: Git, Jenkins, CI/CD, JIRA, Agile, Scrum

- Leadership, Team Management, Mentorship
- Communication, Problem Solving, Critical Thinking
- Project Management, Time Management
- Collaboration, Cross-functional Teams
